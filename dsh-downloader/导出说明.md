# dsh-dl-manager —— 导出 / 安装说明

一个 DSH 左侧栏的「下载管理器」插件：粘贴网址 → 自动识别下载（小红书 / HLS 直链 / B站·抖音·快手·TikTok 等全平台），带状态分类、分页、播放/查看、设置页。

本插件**自包含**：引擎（lib/engine.js）、界面（public/）、客户端（lib/client.js）、下载脚本（scripts/）全部在插件目录内，不依赖 `/ai/skills` 等外部技能目录。

---

## 一、目录结构

```
dsh-dl-manager/
├── package.json          # DSH 插件声明（dsh.bundle.patch + dsh.client.platform=web）
├── cordis.patch.yml      # 注册进 DSH 的 bundle
├── lib/
│   ├── index.js          # 宿主壳：注册 /dsh-dl-manager 路由 + 按 mtime 热加载 engine.js
│   ├── engine.js         # 全部业务逻辑（任务队列、下载、API、配置）
│   └── client.js         # 客户端：左栏「下载」面板 + 主程序代发 fetch 的桥
├── public/
│   └── index.html        # 面板界面（分类标签/分页/设置页）
└── scripts/
    ├── dl_hls.sh         # HLS 专用下载（N_m3u8DL-RE + ffmpeg faststart）
    └── xhs_note.py       # 小红书笔记下载（图/视频/正文/评论）
```

## 二、安装到另一台 DSH

1. 把整个 `dsh-dl-manager/` 目录放到目标机器的 DSH profile 目录，例如：
   ```bash
   cp -r dsh-dl-manager /data/.dsh/profiles/web/dsh-dl-manager
   ```
2. 在 profile 的 `package.json` 里登记（两处）：
   - `dependencies` 加 `"dsh-dl-manager": "link:./dsh-dl-manager"`
   - `dsh.profile.bundles` 数组里加 `"dsh-dl-manager"`
3. 在 `node_modules` 里建软链（pnpm 场景必须，否则会被当 extraneous 移走）：
   ```bash
   ln -sfn ../dsh-dl-manager node_modules/dsh-dl-manager
   ```
4. **重启 DSH 网关**（宿主插件只在进程启动时加载）。左侧栏出现「下载」即成功。

## 三、依赖（需在机器上可用）

| 工具 | 用途 | 默认查找 |
|---|---|---|
| `yt-dlp` | 全平台视频（B站/抖音/快手/TikTok/微博…） | 裸命令名，走 PATH；或设置页填绝对路径 |
| `ffmpeg` | 合并/转封装、faststart | 同上 |
| `ffprobe` | 校验视频流 | 同上 |
| `python3` | 小红书笔记脚本 | 同上 |
| `N_m3u8DL-RE` | HLS 直链下载器 | 同上（或设置页填绝对路径） |

> 若这些工具不在 PATH 里，打开面板「设置」页填绝对路径即可；也可以把它们的目录加到「工具 PATH 前缀」。

## 四、配置（面板「设置」页，或环境变量）

设置页保存后写入 `config.json`（默认在数据目录 `/data/.dsh/dl-manager/config.json`）。

| 设置项 | 环境变量 | 默认值 |
|---|---|---|
| 下载目录 | `DLM_DOWNLOAD_DIR` | `<数据目录>/downloads`（可在设置页改成你的路径） |
| 临时目录 | `DLM_TMP` | `<数据目录>/tmp_down` |
| python3 | `PYTHON3` | `python3` |
| yt-dlp | `YTDLP` | `yt-dlp` |
| ffmpeg | `FFMPEG` | `ffmpeg` |
| ffprobe | `FFPROBE` | `ffprobe` |
| N_m3u8DL-RE | `RE_BIN` | `N_m3u8DL-RE` |
| 工具 PATH 前缀 | `DLM_BIN_PATH` | 空（用系统 PATH；工具不在 PATH 时在设置页填绝对路径） |
| 数据目录（任务记录/日志/配置） | `DLM_DATA` | `/data/.dsh/dl-manager` |
| 脚本目录 | `DLM_SCRIPTS` | 插件自带 `scripts/` |

优先级：`config.json` 文件 > 环境变量 > 默认值。

**给朋友的机器**建议显式设置 `DLM_DATA`（可写目录）和 `DLM_DOWNLOAD_DIR`（下载落点）。

## 五、打包

```bash
cd /data/.dsh/profiles/web
tar czf dsh-dl-manager.tar.gz dsh-dl-manager
```
把 `dsh-dl-manager.tar.gz` 发给朋友，按「二」安装即可。

## 六、说明 / 限制

- **代理**：国内站点（小红书/B站/抖音等）会自动直连、不走 `HTTP_PROXY`；外站才走代理。若机器没有代理，直连也能用。
- **YouTube**：YouTube 反爬会要求登录 cookie（`Sign in to confirm you're not a bot`）；本插件未内置登录态，YouTube 可能下不动，属 YouTube 侧限制。
- **HLS 伪装头**：部分站点的 m3u8 分段是「PNG 头 + 真 TS」，`scripts/dl_hls.sh` 已处理。
- **数据不丢**：任务记录/日志在数据目录（持久化），重建容器/升级插件不影响历史。
- **热加载**：改 `lib/engine.js` 后下一次请求自动重载，**改下载逻辑不需要重启网关**；只有改 `lib/index.js`（壳）才需要重启。
